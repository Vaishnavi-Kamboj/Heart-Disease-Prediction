# ❤️ Heart Disease Prediction using Machine Learning

A web-based Heart Disease Prediction System built using **Machine Learning** and **Streamlit**. The application predicts whether a patient is at risk of heart disease based on medical parameters entered by the user.

---

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. Early prediction can help individuals seek timely medical attention.

This project uses a **K-Nearest Neighbors (KNN)** machine learning model trained on a heart disease dataset to predict the likelihood of heart disease.

---

## 🚀 Features

- ❤️ User-friendly Streamlit interface
- 📊 Real-time heart disease prediction
- 🤖 Machine Learning (KNN Algorithm)
- 📋 Patient information summary
- 💡 Health recommendations based on prediction
- 📱 Responsive and easy-to-use interface

## 📊 Input Parameters

The application takes the following inputs:

- Age
- Gender
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- Old Peak
- ST Slope

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Heart-Disease-Prediction.git
```

Move into the project folder

```bash
cd Heart-Disease-Prediction
```

Install the required libraries

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
